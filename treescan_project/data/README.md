- **Tree_file_2026.csv** – A list of every eligible ICD-10-CM code, its parents, and its description as generated by Ramona Lall and Alison Levin-Rector (NYC Health Department). This version is for FY2026 (April 2026–September 2026). The distance_between field is required by TreeScan and is set to 1 for all rows.
Codes are distinguished by whether the patient was admitted (“1-” prefix) versus not admitted (“0-” prefix), as well as a parent node (“2-” prefix) indicating any ED visit for that diagnosis, regardless of admission status. It also includes supplemental nodes connecting ICD-10-CM codes on different parts of the tree sharing a common etiology. 
The tree file should be updated when new ICD-10 codes are released by downloading the tree structure provided by the [Centers for Medicare & Medicaid Services](https://www.cms.gov/medicare/coding-billing/icd-10-codes) and appending new codes. This occurs each year in October and might also occur at additional times. We don’t recommend excluding codes from the Tree file that were deleted so that if hospitals are slow to update their systems, these codes are not dropped from the analysis. R code for creating a Tree file and updating it annually and as needed is provided in “1_Create_Tree_File.R.”

- **Do_not_evaluate_nodes.csv** – A list of ICD-10-CM codes that are included in input files but are not evaluated because (a) diagnoses are too broad to be actionable (tree level 4 for 2- nodes), (b) diagnoses are for the subset of ED patients who were not admitted (“0-” prefix), because we’re only interested in signals of diagnoses for ED patients overall (“2-” prefix) or the subset admitted (“1-” prefix), or (c) diagnoses are too specific to plausibly reflect population-level emergent health issues, such as diagnoses distinguishing whether a health issue was for the left, right, bilateral, or unspecified sides of the body. Tree levels 1, 2, and 3 are also not evaluated because they are too broad to be actionable, but this is specified separately in the excluded-tree-levels parameter setting. The “*” wildcard symbol at the end of a node in the ‘do not evaluate nodes’ file indicates all subcodes are not evaluated. For example, ‘N63*’ will exclude ‘N63.1’ and ‘N63.3.1’ but not ‘N63.’ This file was generated by Alison Levin-Rector (NYC Health Department).
Whenever the Tree file is updated to incorporate new ICD-10 codes, this file should also be updated. Any newly added codes should be temporarily included in this file until the analysis data time range (90 days) has elapsed to avoid false signals that are driven by their recent introduction. 

- **Common_cause.csv** – A list of supplemental nodes connecting ICD-10-CM codes on different parts of the tree sharing a common etiology, as generated by Alison Levin-Rector (NYC Health Department). These codes are included in the Tree file. The supplemental nodes allow TreeScan to scan not only for increases on the same tree branch, but also for increases in illnesses caused by a common pathogen.

- **Tree_file_2026_wide_format.txt** – This is a version of the Tree File in wide format that is used by the R code that creates the count file. It is used to merge in parents to the raw input data.
